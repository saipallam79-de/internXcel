# API documentation

The running FastAPI application exposes interactive OpenAPI documentation at `/docs`.

Core routes include:

- `POST /api/auth/register`
- `POST /api/auth/login`
- `GET /api/domains`
- `POST /api/internships/apply`
- `GET /api/internships/{user_id}`
- `GET /api/modules`
- `GET /api/tasks`
- `GET /api/certificate/verify/{certificate_id}`
- `GET /api/admin/stats`
